# EXCERPT STUDIO — GitHub Pages 즉시 업로드용

React, Node.js, npm, GitHub Actions 없이 작동하는 정적 웹 발췌기입니다.

## GitHub Pages에 올리기

1. GitHub에서 새 **Public** 저장소를 만듭니다.
2. **index.html, style.css, app.js** 파일을 저장소 **최상위(root)** 에 업로드합니다. ZIP 자체를 올리는 게 아닙니다.
3. `Settings` → `Pages` → `Build and deployment`에서 **Deploy from a branch**를 선택합니다.
4. Branch는 **main**, Folder는 **/(root)** 로 고른 뒤 Save 합니다.
5. 배포가 완료되면 `https://사용자이름.github.io/저장소이름/` 으로 접속합니다.

`index.html`을 더블클릭해서 로컬 브라우저에서 열어도 됩니다.

## 포함된 기능

- 한 화면에서 전체 원문 입력 (contenteditable), 일반 텍스트 붙여넣기
- 굵게, 기울임, 밑줄, 취소선, 글자색
- 현재 문단 화자 A/B/서술 지정
- 소설형, 채팅형, 혼합형 미리보기
- 4개 디자인 프리셋, 폰트/글자 크기/행간/여백/배경/화자색
- 헤더·푸터 텍스트, 자동 높이 및 최소 이미지 비율
- 브라우저 Canvas로 미리보기 및 2배 PNG 저장 (외부 라이브러리 불필요)
- 브라우저 자동 저장, JSON 프로젝트 내보내기/가져오기
- PC/모바일 반응형 UI

## 현재 한계

- 화자는 A/B 두 명만 제공하며, 문단별로 수동 지정해야 합니다.
- HTML 붙여넣기는 일반 텍스트로 변환되며, 원문의 플랫폼별 대화 형식을 자동 구분하지 않습니다.
- 긴 글이 브라우저의 캔버스 크기 제한을 넘으면 PNG 생성이 실패할 수 있습니다. 다음 버전에서 분할 출력을 추가할 예정입니다.
- 글자 서식은 편집 영역에서 문장별로 적용할 수 있습니다. 일부 브라우저에서 Ctrl+Z 등의 동작은 브라우저 구현을 따릅니다.
- 이미지 비율은 **최소 높이**로 적용됩니다. 텍스트가 긴 경우 잘리지 않도록 높이가 늘어납니다.

## 개인정보

외부 API, 서버, 추적 스크립트가 없습니다. 프로젝트는 브라우저의 localStorage에만 자동 저장됩니다.
