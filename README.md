# EXCERPT STUDIO v0.4 — GitHub Pages 버전

## 설치 없이 배포
1. ZIP 압축을 해제하세요.
2. `index.html`, `style.css`, `app.js`, `README.md` 네 파일을 GitHub 저장소 **루트**에 업로드하세요. ZIP 자체를 업로드하지 마세요.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/(root)` → Save.
4. 배포 후 `https://사용자이름.github.io/저장소이름/`에서 접속하세요.

HTML 파일을 더블클릭해서도 실행할 수 있습니다. 폰트(구글 폰트)를 내려받으려면 인터넷 연결이 필요합니다. 폰트 네트워크 연결이 실패하면 시스템 대체 폰트가 사용됩니다.

## 주요 기능
- 통합 리치텍스트 편집기 (굵게, 기울임, 밑줄, 취소선, 선택 글자색)
- 문단별 캐릭터 지정 및 16명까지 캐릭터 추가·색상 수정
- 소설형 / 채팅형 / 혼합형 미리보기
- 제목 / 부제목 / 출처의 크기 및 좌·중·우 정렬
- 한국어 웹폰트 다수, 실시간 캔버스 렌더링
- 단색 배경 및 로컬 이미지 업로드, 이미지 농도, 흰색 가독성 베일, 이미지 위치 / 맞춤
- 900×900, 900×1200, 900×1600 및 커스텀 고정 높이 페이지 자동 분할
- 2배 해상도 PNG / 다중 이미지 ZIP, 프로젝트 JSON 내보내기·불러오기, 브라우저 자동 저장

## 이미지 업로드 및 개인정보
- 이미지는 사용자 브라우저에서 축소/압축되고 프로젝트 데이터에 포함됩니다. 서버로 별도 전송하지 않습니다.
- 용량이 큰 이미지는 브라우저 localStorage 용량 제한으로 자동 저장이 실패할 수 있습니다. 그런 경우 상단 **프로젝트 저장**으로 JSON 파일을 별도로 백업하세요.
- Google Fonts는 외부 서비스입니다. 문서 내용이나 업로드한 이미지를 해당 서비스로 전송하는 코드는 없습니다.

## 제약
- 현재 페이지 가로 폭은 900 CSS 픽셀로 고정이며 세로 높이만 커스텀 지정 가능합니다.
- 페이지 분할은 실제 캔버스 글자 너비와 줄 높이 계산을 사용하며 한 문단이 길어도 이어지는 페이지로 나눕니다. 고급 문장부호 금칙 처리 및 다단 조판은 아직 지원하지 않습니다.
- 초장문/초대형 이미지의 PNG 내보내기는 브라우저 캔버스 크기 및 메모리 제한의 영향을 받습니다.
- PNG 내보내기는 브라우저 캔버스 기반으로, 미리보기와 동일한 렌더러를 사용합니다.

## 개발 상태
JavaScript `node --check` 및 파일 구조 검사를 완료했습니다. 실제 GitHub Pages 배포와 여러 브라우저 클릭 테스트는 별도로 진행해야 합니다.
