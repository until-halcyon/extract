# EXCERPT STUDIO v0.3

AI 채팅 통합 발췌기 — 순수 HTML / CSS / JavaScript. **npm 설치나 빌드가 필요 없습니다.**

## GitHub Pages 배포

1. ZIP 파일의 압축을 풀고 `index.html`, `style.css`, `app.js`를 저장소 최상위(root)에 업로드합니다. **ZIP 파일을 그대로 업로드하지 마세요.**
2. 저장소 Settings → Pages → Build and deployment → Source: **Deploy from a branch**를 선택합니다.
3. Branch: `main`, Folder: `/(root)`를 선택하고 Save 합니다.
4. 배포 완료 후 `https://사용자명.github.io/저장소명/` 에 접속합니다.

로컬에서는 `index.html`을 열면 됩니다. 웹폰트는 인터넷 연결 시 내려받으며, 오프라인에서는 대체 시스템 폰트가 적용됩니다.

## 주요 기능

- 01 / CONTENT를 줄이고 03 / RESULT를 넓힌 3열 레이아웃
- 소설형, 채팅형, 혼합형 + 실시간 미리보기
- **캐릭터 추가/삭제, 이름/색상 지정, 문단별 캐릭터 지정** (최대 16명)
- 한국어 웹폰트 13종 포함 총 16개 글꼴 선택
- **제목·부제목·출처** 각각 내용, 크기, 좌/중/우 정렬 설정
- **고정 페이지 크기** 1:1(900×900), 3:4(900×1200), 9:16(900×1600), 사용자 높이 (900×600~4000)
- 페이지에 다 들어가지 않는 글은 **줄 단위 자동 페이지 분할**
- 단일 페이지 PNG 저장, 여러 페이지는 **PNG가 들어 있는 ZIP** 다운로드 (2배 해상도)
- 로컬 자동저장 + JSON 프로젝트 파일 가져오기/내보내기

## 참고

- 캔버스 기반 출력입니다. 미리보기와 다운로드가 동일한 페이지 레이아웃을 사용합니다.
- 제목/부제목은 모든 페이지의 상단에, 출처는 모든 페이지의 하단에 반복 표시됩니다.
- 자동 페이지 분할은 현재 **줄 단위**이며, 긴 문단도 페이지 사이에서 이어질 수 있습니다.
- 글자 선택 서식 기능은 브라우저의 `execCommand`를 사용하므로 브라우저별 편차가 있을 수 있습니다.
- 아주 긴 이미지나 수백 페이지짜리 결과물은 브라우저 메모리 한계에 걸릴 수 있습니다.
- 별도의 서버로 원문을 전송하지 않습니다. Google Fonts 웹폰트 리소스만 외부에서 로드합니다.
